# EnkelLGH brand kit

The site serves these files from `/brand/`. The colours are the site's own: `packages/shared/src/format/design.ts` is
the source, and this list follows it.

## Name

* **EnkelLGH**: one word, LGH in capitals. Paid tier: **EnkelLGH Plus**.
* Domain **enkellgh.se**, printed as EnkelLGH.se.
* Never: Enkel LGH, EnkelLgh, Enkellgh, ENKELLGH.

## Files

| File | Use |
| --- | --- |
| `logo.svg` | Symbol tile + wordmark on white (default; site navbar) |
| `logo-on-ink.svg` | On dark backgrounds (site footer) |
| `logo-white.svg` | All white, on the accent or on photos |
| `wordmark.svg`, `wordmark-on-ink.svg`, `wordmark-white.svg` | Wordmark without the symbol |
| `symbol.svg` | The symbol (Radien) alone, no tile |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | Browser tab; `favicon.svg` is also the app icon and the navbar logo under 380 px |
| `apple-touch-icon.png` | iOS home screen (180 × 180) |
| `icon-192.png`, `icon-512.png` | App icon, for a web manifest |
| `social-avatar.png` | Profile picture on Instagram, LinkedIn, Facebook (400 × 400) |
| `og-image.png` | Link preview when the site is shared (1200 × 630) |

The text in every SVG is outlined, so it looks the same with or without the font installed. Clear space: half the
symbol's height on every side. Minimum size: symbol 16 px, wordmark 72 px wide.

## Logo

`Enkel` in regular weight, `LGH` in 800 in the accent, letter spacing about −0.035 em. The symbol, Radien, is the
dashed travel-time circle from the map with a dot in the centre, on an accent tile with rounded corners.
